
# 📚 Multi-Agent Study Assistant

An intelligent **AI-powered study assistant** that leverages multiple agents to enhance learning, simplify complex topics, and provide interactive academic support.

## 🚀 Overview

The **Multi-Agent Study Assistant** is designed to help students understand concepts more effectively by combining multiple AI agents, each specializing in different tasks such as explanation, summarization, and question answering.

This system improves learning efficiency by breaking down complex topics into simpler, understandable formats.

---

## 🎯 Features

* 🤖 Multi-agent architecture for smarter responses
* 📖 Concept explanation in simple terms
* 📝 Automatic summarization of study material
* ❓ Question-answering support
* 📊 Structured and interactive outputs
* ⚡ Fast and user-friendly interface

## 💻 Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

2. Create virtual environment (optional but recommended):

```bash
conda create -n study_env python=3.10
conda activate study_env
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Usage

Run the application using:

```bash
streamlit run app.py
```

Then open your browser at:

```
http://localhost:8501
```

---

## 📊 How It Works

1. User provides input (topic/question)
2. Input is processed by multiple AI agents
3. Each agent performs a specific task:

   * Explanation Agent
   * Summarization Agent
   * QA Agent
4. Results are combined and displayed to the user
